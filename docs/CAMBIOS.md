# Registro de versión

## 0.1.0 · 28/08/2026

Primera implementación local para revisar el análisis y los casos de uso.

- Servidor Node.js y almacenamiento SQLite, con datos ficticios iniciales.
- Interfaz en español con navegación de personas, grupos, usuarios y guía.
- Perfiles de administración, catequista y consulta del arzobispado.
- Asignaciones por grupo, altas mínimas y edición de fichas.
- Foto, carga de archivos y consulta con control de acceso.
- Validaciones, conflictos de edición, protección de última cuenta administradora y último catequista de grupo ocupado.
- Documentación de uso, arquitectura, decisiones abiertas y pruebas.

No se ha desplegado en AWS ni se han cargado datos reales. No se ha importado ningún Excel ni se ha cambiado el Word previo de análisis. La nueva entrega es el código local, su interfaz compilada y esta documentación.
